# Security policy

## Supported versions

Only the latest release gets security fixes. Update to it before reporting.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through
[GitHub's private vulnerability reporting](https://github.com/YuriyWozniak/qrzlite-sitemap/security/advisories/new)
with:

- the version of the package, Joomla and PHP;
- what an attacker can do and what they need (an account, a crafted URL, access to the console…);
- the steps to reproduce it.

This is a one-maintainer project; reports are answered as soon as possible. Once a fix is released, the advisory
is published with credit to the reporter, unless they prefer not to be named.
